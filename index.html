Three projects, in depth

Each one opens a page with the full story: the problem, the decisions, the results and where the code lives.

A pion field for the large-scale universe

Co-authored a paper and co-wrote the simulation code with my advisor. I took its FFT-based solver from a Mathematica prototype to C++.

  • Paper: arXiv:2604.12009 (2026)
  • About 400 times faster than the first prototype
  • Seven conference talks, 2022 to 2025
Read the project story

Simulating the universe, fast

My honors thesis: a custom mixed-radix FFT and CPU parallelization in C++, checked against the standard FFTW3 library.

  • Matches FFTW3 to about 1e-12
  • 2.6 to 3.3 times faster with 8 threads on large grids
  • Manhattan University, 2025
Read the project story

MediChat chatbot, from raw data to deployment

I built the chatbot for a team health-consultation app: data filtering, model comparison and training, and a hybrid chat system.

  • Four models compared, RoBERTa selected
  • 31 hits locally, 56 after cluster training, on a small 200-pass test
  • Four iterations delivered to the frontend team
