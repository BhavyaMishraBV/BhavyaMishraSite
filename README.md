# BhavyaMishraSite

Portfolio site for Bhavya Mishra. Plain HTML, CSS and JavaScript, with no build step.

- `index.html`: landing page
- `projects/`: three project story pages
- `assets/`: styles, scripts, images and video

## Make it yours

- Replace `assets/video/hero.mp4` with your own clip.
- Optional project hero clips: `assets/video/pion.mp4`, `thesis.mp4`, `capstone.mp4`. Without them, the animated scenes show.
- Search the files for `TODO` and fill in LinkedIn, email and the Econolite blurb.
- Email and the optional form service are set at the top of `assets/js/site.js`.

## Run locally

    python3 -m http.server 8000

Then open http://localhost:8000.
